# Stephen Ismaila — Portfolio Website

A responsive dark-themed portfolio made with plain HTML, CSS, and JavaScript. No framework or build tools are required.

## Files

- `index.html` — page content and project information
- `styles.css` — layout, colors, responsive styles, and animations
- `script.js` — mobile navigation and automatic footer year

## Run it locally

1. Extract the ZIP file to a folder on your computer.
2. Open the `stephen-portfolio` folder in Visual Studio Code or Visual Studio.
3. Open `index.html` in a browser. If you use Visual Studio Code, the Live Server extension is optional; you can also double-click `index.html` in File Explorer.
4. Edit the files, save, and refresh the browser to see changes.

## Personalize before publishing

Open `index.html` and search for these placeholders:

- `YOUR_EMAIL@example.com` — replace with your professional email address.
- `YOUR_GITHUB` — replace with your GitHub username.
- `YOUR_LINKEDIN` — replace with your LinkedIn profile slug.

Also review the About, Skills, and Projects sections. Keep only skills you can discuss honestly, and update project descriptions to match your final code. Add GitHub repository links when your projects are published.

## Publish free with GitHub Pages

1. Create or sign in to a GitHub account at https://github.com.
2. Create a new public repository named `your-github-username.github.io` (replace the example with your actual username).
3. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository's root folder.
4. In the repository, open **Settings → Pages**. Under build/deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to deploy. Your site will normally be available at `https://your-github-username.github.io/`.

GitHub may take a few minutes to publish the first time. Do not upload private information, passwords, or documents you do not want public.
